# 设计符合性核验报告（Design Verification）

> **核验对象**：当前 `run_case.py` + `src/hil_mc/` 实现与产物（`analysis/case_40nm_bulk/`、`analysis/case_nature/`）
> **设计基线**：① 用户指定：胶厚 **40 nm** / 衬底 **670 µm Si** / He⁺ **30 keV**；② 早期 "final experiment" 定义：Ti₆-oxo 胶、**10 nm 孤立线**、耦合 XRR 实测粗糙度 σ=0.73 nm，并给出 NILS≈9.2、最佳剂量 38 pC/cm、LER₃σ≈0.87 nm、工艺窗口 18–70 pC/cm、Si 内 Bragg 峰≈160 nm。

## 一、总体结论

**结论：部分实现。** 材料—输运—PSF—NILS—LER 的**计算链路已完整打通并自洽**；但**设计指标本身（10 nm 线宽下的 LER 与工艺窗口）尚未闭合**，且当前给出的 "0.2 nm LER" 与早期 "0.87 nm LER" 的 4 倍差异**不是计算错误，而是粗糙度是否入模 + 绝对剂量是否标定**这两个建模选择造成的。

| 维度 | 状态 |
|---|---|
| 几何/材料/束流条件（40 nm / 670 µm / 30 keV / CIF / XRR 密度） | ✅ 实现 |
| 蒙特卡洛输运 + SRIM 标定 + PSF/LSF/NILS/LER/工艺窗口 | ✅ 实现（精度 ±4%） |
| 4 张图 + HTML 报告 + JSON + Nature 风格重绘 | ✅ 实现（含超额交付） |
| **设计线宽 10 nm 下的 NILS/LER/剂量窗口** | ❌ **未实现**（当前最优 CD=7.58 nm；强行约束到 10 nm 则 NILS 崩塌到 2.0、LER 升到 0.81 nm） |
| **XRR 粗糙度 σ=0.726 nm 耦合进 LER** | ❌ **未实现**（仅解析并打印，未进入物理） |
| **绝对剂量轴标定（D₀/D₁₀₀/γ）** | ❌ **未实现**（阈值 ρ_gel=15 eV/nm³ 为假设值） |
| **Si 内深度剂量曲线（Bragg 峰）** | ❌ **未建模**（`depth_profile` 仅覆盖 0…t_resist） |
| 4 项后续专题图（灵敏度/3D 线形/曝光宽容度/热与溅射） | ❌ 未实现 |
| 4 类实验输入（显影动力学 / CD-SEM / 截面 / XPS-FTIR） | ⚠️ 待用户提供 |

## 三、与早期 "final experiment" 数值的分歧与根因

| 量 | 早期套件 | 当前实现 | 分歧根因 |
|---|---|---|---|
| LER₃σ | 0.87 nm | 0.198 nm（随机项）/ 0.753 nm（+σ） | **早期把 XRR 粗糙度 σ=0.73 nm 直接耦合**（主要贡献项）；当前只算散粒噪声，σ 未入模 |
| 最佳剂量 | 38 pC/cm | 251 pC/cm（无约束）/ 666 pC/cm（CD=10 nm） | 阈值得失假设不同（ρ_gel=15 eV/nm³），且**无 D₀/D₁₀₀ 实验标定**，剂量轴为模型相对量 |
| NILS | 9.2 @10 nm | **7.00 峰值 @CD=7.72 nm**；2.02 @CD=10 nm | 达到 10 nm 所需剂量（666 pC/cm）已进入 PSF 拖尾主导的过曝区 |
| PSF FWHM | 1.1 nm | 2.00 nm | SE1 离域 σ=0.65 nm + 散射；口径/膜厚不同 |
| Bragg 峰 | ≈160 nm | 未建模（轨迹反推 208.7 nm） | 当前 MC 只记录胶内深度剖面 |

**关键判断**：两套数字都"自洽"，但**回答的是不同问题**——早期 0.87 nm 是"含膜面粗糙度的实测预期 LER"，当前 0.198 nm 是"仅随机效应的物理下限"。**论文/报告中必须明确标注口径**，否则会被审稿人质疑。

## 四、必须修复的三个 P0 建模缺口

### 4.1 LER 缺少粗糙度/相关长度耦合
`metrics.py:187` 只有 `ler1 = cd/(nils*sqrt(n_edge*a_eff))`，即纯散粒噪声。XRR 实测 σ=0.7262 nm 已解析（`run_case.py:75`）却只用于打印。
- 影响：当前 0.198 nm 是**下限**而非预测值；与"亚 nm LER"结论的可信度直接相关。
- 建议：引入 `LER_total² = LER_stoch² + σ_eff²`，其中 σ_eff 需按相关长度 ξ 折算（XRR 的 σ 是长程面形起伏，直接全额叠加是**上界**）。当前全额叠加得 0.753 nm（可复现早期的 0.87 nm 量级）。
- 需要的输入：CD-SEM 实测 LER 与相关长度 ξ（用于确定 σ_eff 的权重）。

### 4.2 绝对剂量轴未标定
阈值 `RHO_GEL = 15 eV/nm³`、`W_SE = 20 eV` 均为假设；`a_eff=9.33 nm²` 是靠"悬空膜 LER=0.21 nm"这一文献目标反标定的。
- 影响：所有"最佳剂量/工艺窗口"绝对值不可直接对实验下指令；251 vs 38 pC/cm 的 6.6 倍差异无法判别谁对。
- 建议：用**对比度曲线实验**（膜厚-剩余率 vs 剂量）测定 D₀、D₁₀₀ 与 γ，把 ρ_gel 换成实测凝胶剂量。

### 4.3 CD 无下限/无目标约束 → 优化落入退化区
剂量扫描显示（CD 下限取分子尺寸 2.24 nm）：

| 剂量 (pC/cm) | CD (nm) | NILS | LER₃σ (nm) | 判定 |
|---|---|---|---|---|
| 1.0 | 0.57 | 0.41 | 0.248 | ❌ CD < 分子尺寸 |
| 3.0 | 1.52 | 1.20 | 0.228 | ❌ CD < 分子尺寸 |
| 10.0 | 2.60 | 1.44 | 0.325 | ok |
| 40.1 | 4.28 | 1.96 | 0.391 | ok |
| **251.4** | **7.58** | **6.87** | **0.198** | ← 当前"最优" |
| 665.6 | 9.10 | 2.02 | 0.808 | CD=10 nm 约束点 |
| 1996.8 | 16.83 | 3.00 | 1.005 | 严重过曝 |

- 影响：`results.json` 中 23.7 nm 工况的"最优"（CD=1.52 nm、NILS=1.86、LER=0.147 nm）**物理上不成立**；**胶厚扫描"15–80 nm LER 基本持平（0.19–0.27 nm）"的结论落在退化低剂量角，属假象**——这也解释了为什么图 4c 工艺窗口在左下角出现大片低 LER 平台。
- 建议：(a) 在 `dose_sweep`/`evaluate_line` 中加入 CD 合法区间 `[CD_min≈3×分子尺寸, CD_max]`，或 (b) 改为**固定 CD 目标**下的剂量寻优（即"曝光宽容度"口径）。

## 五、建议的下一步（按优先级）

**P0（决定结论是否成立，建议先做）**
1. 明确设计口径：**40 nm（设计）还是 23.74 nm（XRR 实测）**为主工况？当前主工况是 40 nm，与样品 4 的实测膜不符。
2. 明确 LER 口径并二选一：只报随机下限（≈0.2 nm，需注明），或耦合粗糙度报预测值（≈0.75 nm）。
3. 给 `dose_sweep` 加 CD 下限/目标约束，重跑胶厚扫描与工艺窗口（现结论不可信）。

**P1（补齐全套图表）**
4. 输出"曝光宽容度"图：固定 CD=10 nm±10%，给出允许剂量抖动（现已算出 656–929 pC/cm，但 LER 已劣化到 0.81 nm，需先解决 P0-2）。
5. 增加 Si 内深度剂量曲线（`depth_profile` 扩展到衬底），以支撑"SE2 本底/Bragg 峰"叙述。
6. 灵敏度/对比度曲线、3D 线形、热与溅射窗口：需显影动力学与溅射产额模型（缺模块 + 缺实验输入）。

- 不同剂量下的 CD-SEM 顶视图 → 实测 CD/LER/LWR/**相关长度 ξ**
