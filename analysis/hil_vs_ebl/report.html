1. 结论摘要

核心发现：在孤立线口径下，HIL 的边缘锐度由二次电子离域决定 （LSF 半高宽约 2.3 nm），而 EBL 由前散射范围 α 决定。 文献参数下 30 kV EBL 的 α ≈ 59 nm、 100 kV ≈ 7.3 nm —— 即 升压只把 EBL 的模糊从几十 nm 压到约 10 nm，而 HIL 天然处于 ~1 nm 量级。
最关键的物理差异不是"边缘有多陡"，而是"能量落到哪里"： EBL 有 43% 的沉积能量来自背散射电子、铺展在 β ≈ 4–31 µm 尺度上 （η ≈ 0.74）；HIL 的对应长程本底只有 4.37% （衬底 SE2 回注），离子背散射仅 1.478%。 这正是 HIL 在密排图形（光栅）中邻近效应可忽略的根源。
必须诚实说明的边界：在大线宽（CD ≳ 50 nm）下，双高斯 EBL 的 边缘斜率随 CD 增大而变陡，其 LER 会逼近甚至优于 HIL 的幂律尾部（见 §4 表与图 d）。 HIL 的决定性优势集中在 小线宽（CD ≲ 20 nm），也正是亚纳米 LER 与高分辨光栅所关注的区间； 密排图形中 EBL 还要再叠加 η≈0.74 的图案密度依赖本底，HIL 没有这一项。

2. 方法：为什么两条路径可以同台比较

两支束流走同一套显影边缘模型：显影边界是线扩散函数跨越抗蚀剂阈值的位置， 像对数斜率 NILS = CD·|dlnE/dx|，随机 LER 用项目既有公式

LER(3σ) = 3·CD / (NILS·√(n_A·a_eff)) = 3·σ_edge / √(n_A·a_eff)

其中 n_A = ρ_gel·t/ω_SE = 30 events/nm²、a_eff = 9.17 nm² 两支束流取同一组值（抗蚀剂化学相同），因此差异完全归因于 PSF 形状。 又因显影边界只取决于「阈值/剂量」之比，扫描该比值等价于扫描剂量， 所得 (CD, NILS) 轨迹与绝对剂量标定无关——这才使 He⁺ 蒙特卡洛的绝对单位（eV/nm/ion） 与电子的任意单位可以直接对照。注意 LER 可化简为 3σ_edge/√(n_A·a_eff)， CD 只通过"边缘落在哪里"进入。

6. 口径与局限

  • EBL 参数为文献假设值：Tabulated parameters are for a 0.5 um resist on Si. alpha grows steeply with resist thickness (Eq. 10), so for a 40 nm film the pure scattering term is much smaller; the 'ebl_resist_scaled' branch applies Eq. 10 plus a 3 nm probe spot as the sensitivity band. Real tools always add a probe term, which the literature alpha implicitly carries.
  • HIL 的绝对剂量轴未标定（ρ_gel、ω_SE 为假设，a_eff 为反标定），故 LER 是随机下限而非绝对预测。
  • 两支束流共用 a_eff 与 n_A，属受控比较，用于隔离 PSF 形状贡献。
  • 模型无显影动力学项，未包含抗蚀剂溶解随机性与线宽粗糙度（LWR）的独立贡献。
  • 本次顺带修复：metrics.converged_lsf() 原先只返回正半轴，导致 CD 被当作半宽、 NILS 低估 2×（LER 不受影响）。已改为镜像为完整对称网格。
